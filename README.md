# SiteCtrl Starter

**SiteCtrl** — Control, Monitor & Protect Your Websites.

## Start in VS Code

```bash
npm install
npm run dev
```

Open: http://localhost:3000

## Environment

Copy `.env.example` to `.env.local` and add Supabase / Resend / PageSpeed keys when ready.

## Included

- Landing page
- Login / Signup UI
- Dashboard mockup
- Add website page
- Website detail page
- Basic API placeholders
- Supabase client helper
- Initial SQL schema

## Suggested next step

Connect Supabase Auth and replace mock data with database records.
